# 规划：内网分享（LAN Share）——浏览器直接看，免装 ddpView

> 状态：**仅规划，未实施**。建议落点：0.4.x（纯壳层功能，不依赖 deepdesign-core 拆分）。
> 一句话：deepDesign 桌面端一键把当前项目变成内网可访问的只读网页
> （`http://<内网IP>:<端口>/<token>`），同事手机/电脑浏览器直接点着看——
> 不用发 .ddp 文件、不用装 ddpView。
> 事实核查日期：2026-09-29。

## 1. 结论先行

**可行且成本低（2–4 天出 P1）**，因为关键积木都在：

- 引擎经典导出 `export_html_in`：**自包含可交互 HTML 原型**（mbt 进 → `{ok,html}` 出，
  前端"导出 HTML 原型"菜单已在用它）——共享 = 把这份 HTML 经 HTTP 送出去，零格式工作；
- tokio 已启用 `net` feature，hyper 1.x 栈已随 reqwest 在依赖树里——起一个 HTTP 服务
  几乎不新增编译产物（备选 tiny_http，更小但多一个依赖）；
- 监听端口是纯 Rust 行为，不占 Tauri capability 预算，CSP 也不相干（服务对象是外部浏览器）。

**与 ddpView 的关系**：互补不是替代。内网分享解决"旁边的人看一眼"；
正式交付/离线分发给外部人，仍是 DDP + ddpView 那条链路。

## 2. 核心设计：每次 GET 现导出（serve-fresh-per-GET）

不做快照、不做推送——**每个查看请求现场执行一次 `export_html`**：

```
查看者 GET /t/<token>/
  → Rust 侧经 EngineHost 直调 export_html（只读 op，会话缓存复用，毫秒级）
  → 返回自包含 HTML（单字符串响应，无附属文件）
```

- **永远新鲜**：同事刷新就是最新 canonical——PM 把链接发群里，演示中途 Agent 补了
  一版，看的人刷新一下就是新版。这把"内网分享"从静态截图升级成"看着原型长大"，
  而且没引入任何推送基建（SSE 是 P3 可选增强，见 §6）。
- **零文件系统暴露**：服务器只回一份内存里的 HTML 字符串。不出 .ddp 字节、
  不出目录列表、不出任何路径——没有"下载"这个动作，正是需求本意。
- **零出站请求**：这个服务纯应答，不做 URL 导入、不做代理、不做任何主动外联——
  SSRF 攻击面为零（与 Mimosa 生成前约束的方向一致：出站请求能力一个都不给）。

## 3. 安全清单（逐条落地，缺一不可）

1. **默认关、显式开**：服务器的生命周期 = 分享会话。点"分享"起，点"停止"或退出应用即关。
2. **token 路径**：URL 必须带 128-bit 随机 token（`/t/<token>/`），根路径 404——
   局域网扫描器扫到端口也进不来。可选 PIN（打开页面要输一次）。
3. **绑定面**：`0.0.0.0:<port>`（端口默认随机高位、可改），展示给用户的 URL 用
   自动探测的内网 IP（枚举网卡取私有网段地址；取不到就显示所有候选）。
4. **只读是结构性的**：仅 GET 有响应，其他方法一律 405；无任何写路径。
5. **会话过期**：可选 TTL（默认 2h）；应用退出即失效。
6. **防火墙预期**：Windows 首次监听会弹防火墙授权框（这是 OS 行为），文档与
   分享对话框里说明"允许"即可。
7. **多窗口**：分享绑定发起窗口的项目；切换项目不串台。Agent 运行中分享是安全的
   （export 是只读 op，与画布预览同门）。

## 4. UX 流

- 入口：项目区/topbar「分享」按钮 → 对话框（可选 PIN / 过期时间）→
  展示 `http://192.168.x.x:<port>/t/<token>` + **二维码**（手机扫码即开）+「停止分享」；
- 分享中：topbar 常驻一个呼吸态指示点，点击回到分享面板；
- 查看端：手机/电脑浏览器直接打开，能点交互流程、切换画板（export_html 自带）。

## 5. 工程改动点（全部壳层）

| 改动 | 位置 | 量级 |
|------|------|------|
| EngineHost 分发表加 `export_html` 直调（经典导出，host 只搬运字符串，不解释语义） | wasmtime_host.rs | 小 |
| HTTP 服务模块（hyper 复用现有栈或 tiny_http）：token 路由 + GET 导出 + 405/404 | 新 `src-tauri/src/share.rs` | 中 |
| 内网 IP 探测 + QR 码生成（`qrcode` crate，纯 Rust 无外部依赖） | share.rs / 前端对话框 | 小 |
| 分享对话框 + 常驻指示 + 停止按钮 + i18n（7 语言 T 表同步） | frontend/index.html | 中 |
| 契约测试：token 404 / GET-only / 导出内容含画板 id / TTL 失效 | src-tauri/tests | 小 |

注意：export 每次全量出 HTML，观看者多时在 Rust 侧做 1–2s 节流缓存（同 canonical 直接复用
上次结果），成本恒定。

## 6. 阶段

| 阶段 | 内容 | 出口判据 | 预估 |
|------|------|----------|------|
| P1 | 服务 + token + 导出直调 + 分享/停止对话框 | 手机浏览器（同一 Wi-Fi）打开链接能点完整交互流程 | 2–3 天 |
| P2 | QR、PIN、TTL、防火墙说明、多窗口绑定、节流缓存 | 全部安全清单项有测试锚定 | 1–2 天 |
| P3（可选） | SSE 推送：观看端免刷新跟随 Agent 落笔 | 演示场景实机验证 | 1–2 天 |

## 7. 明确不做（非目标）

- 观看端**不做任何编辑/上传/反馈回写**（只读是产品边界，也是安全边界；
  协同编辑是另一个量级的产品）
- 不做公网穿透/中继（"发链接给外网的人"是另一个产品形态，涉及部署与账号体系）
- 不做账号/登录；PIN 已覆盖"防误看"，防"恶意者"靠 token + 内网边界
- 不废弃 ddpView（正式交付链路不变）

## 8. 待验证项（P1 第一件事）

1. **export_html 自包含性实测**：字体/图片是否全部内联（探针：导出产物断网打开）。
   若存在外链引用，P1 内补"附属资源一并响应"的方案（仍是内存态，不落盘）。
2. **移动端渲染**：1280×800 画板在手机浏览器里的缩放表现（export 的 viewport 处理）。
3. **导出耗时基线**：大文档（多画板）export_html 的毫秒级声明是否成立，定节流参数。
