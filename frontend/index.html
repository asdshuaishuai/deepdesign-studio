快捷键与菜单说明

所有菜单动作最终都经引擎 CLI 落到唯一事实源 .mbt.md

菜单栏 · 文件

⌘N新建项目（模板选择）
⌘O打开 DDP（解密 → MBT 重载）
⌘S保存（导出加密 DDP）
⇧⌘E导出 DDP（设置密码）

菜单栏 · 视图

⌘1 / ⌘2 / ⌘3线框图 / 高保真 / MBT 源码
⌘4演示模式（Esc 退出）
⌘0适配窗口

菜单栏 · 画板

⇧⌘N新建画板
⇧⌘D复制当前画板
⇧⌘F自动修复（引擎还债，违规减少即提交）

画布操作

⌘K聚焦 Agent 指令输入
方向键 / ⇧+方向键移动选中元素 1px / 10px
⌫删除选中元素
双击编辑元素文字
右键元素 / 画布 / 画板 / 源码编辑器菜单

演示模式

点击绿色热区沿交互流导航（tap:xxx）
演示中工作区内禁编辑：隐藏侧栏/检查器/工具条，仅保留跳转
Esc返回上一层 / 退出演示
